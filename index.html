Redesign — UFO Sightings

Crítica e reconstrução de "UFO Sightings over Time" (2026 WK25), a partir do dataset da Kaggle.

Redesign A — Série temporal com escala real

Gráfico de área com d3.scaleTime(): o eixo X respeita a distância real entre datas. Agregação mensal, filtrada a partir de 2020 (período com densidade de dados suficiente para uma leitura honesta da tendência).

Redesign B — Distribuição espacial (EUA)

Cada ponto é um avistamento, projetado com d3.geoAlbersUsa() a partir de latitude/longitude. A cor identifica os formatos ("shape") mais reportados.
